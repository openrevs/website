# OpenRevs website

Published with GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).
GitHub builds it with Jekyll on every push; nothing to install.

- Add a page: create a `.md` file with front matter (`title`, optional `permalink`).
- Change the header/nav/footer: `_layouts/default.html`.
- Change the look: `assets/style.css`.
- Site title/description: `_config.yml`.
